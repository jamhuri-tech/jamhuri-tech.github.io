1. Pilih tempat bekerja

  • Google Colab, tanpa memasang apa pun. Klik tombol Buka di Colab pada kartu praktikum. Notebook dari GitHub bersifat hanya baca, jadi pilih File → Save a copy in Drive sebelum mengisi. Kalau Colab memperingatkan bahwa notebook tidak ditulis oleh Google, pilih Tetap jalankan.
  • Komputer sendiri. Pasang Python 3, lalu jalankan: 
    python3 -m venv metnum
source metnum/bin/activate
pip install numpy scipy matplotlib
    Pada Windows, baris keduanya menjadi metnum\Scripts\activate.

Seluruh kode diuji dengan Python 3.13.5, NumPy 2.1.3, SciPy 1.15.3, dan Matplotlib 3.10.0. Versi yang lebih baru hampir selalu berjalan.

2. Baca bekal dari buku lebih dahulu

Setiap kartu menyebutkan subbab yang harus dibaca sebelum datang ke laboratorium. Bawa bukunya: Metode Numerik: Teori, Algoritma, dan Analisis Galat.

3. Jalankan kerangka sebelum mengisi apa pun

Setiap kerangka sudah berjalan sampai selesai walaupun seluruh TODO masih kosong. Jalankan sekali untuk memastikan alatnya siap. Sesudah itu, isi TODO berurutan dan jalankan ulang setiap kali satu TODO selesai.

4. Baca hasil pemeriksa isian

Setiap kegiatan diakhiri pemeriksaan otomatis:

Periksa isian kegiatan ini:
  [BENAR] TODO 1a  selisih terbagi
  [BELUM] TODO 1b  skema Horner
          polinomial 1 + 2x + x(x-1) di x = 3 dihitung [1.0], seharusnya 13
  • [BENAR] berarti isian itu lolos uji.
  • [BELUM] berarti belum. Baris di bawahnya menyebut angka dari kode Anda dan angka yang seharusnya.
  • [SENDIRI] hanya ada pada Praktikum 1. Label ini tidak diperiksa otomatis, jadi cocokkan sendiri hasilnya dengan petunjuk pada barisnya.
  • Pemeriksa tidak menjawab pertanyaan pada modul. Anda tetap harus menjelaskan sendiri mengapa angkanya begitu.
  • Jangan mengubah bagian yang diapit # >>> pemeriksa dan # <<< pemeriksa.

5. Kumpulkan tugas mandiri

  • satu berkas pNN_nama.py yang berjalan dari awal sampai akhir tanpa galat;
  • berkas gambar bila diminta, dalam bentuk PNG atau PDF;
  • satu berkas PDF berisi jawaban pertanyaan, paling banyak dua halaman.

Yang dikumpulkan berkas .py, bukan .ipynb. Pada Colab, pilih File → Download → Download .py. Jawaban yang hanya berisi angka tanpa penjelasan dinilai separuh.
